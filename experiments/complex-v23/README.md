# v23 隔离研究快照

该目录冻结发布版 `v23` 的网页、动态挠度模型、界面脚本、样式、模型说明和测试，
仅用于复现实验与比较。根目录发布版不会加载这里的任何文件。

## 验证状态

真实测试表明，`v23` 去除等效拉重修正后，推荐动态挠度与预测动态挠度的匹配结果
出现较大误差，因此该版本不能作为可信的复杂计算基线。箭重与箭速存在明显负相关，
也不能在没有同配置实测数据时把两者视为相互独立的输入变量。

当前发布版恢复 `v22`。其等效拉重修正在 30-50 lb 实测范围内表现出一定可靠性，
后续复杂模型应以 `v22` 作为控制组，再对弓档、箭速和通过周期模块逐项标定。

直接打开本目录的 `index.html` 可以运行快照；Node 模型测试命令为：

```text
node experiments/complex-v23/test_model.js
```

## 后续研究边界

- 不直接继承 `v23` 的匹配结论或判定阈值。
- 任何新模型必须先与 `v22` 及真实接触结果进行同条件对照。
- 常见成品挠度候选只按实测满拉拉重与实测拉距生成。
- Easton、Gold Tip、Trophy Ridge 等厂商选箭表独立展示，不并入通用候选。
- 弓把避让的弓档、箭速和通过周期研究位于相邻的 `clearance-cycle` 实验模块。
- 未完成实测标定前，不把复杂模型重新接入根目录发布网页。
