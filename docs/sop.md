# 实射落点记录 SOP

## 1. 建档

1. 确认本次实验目标：基准记录、裸杆测试、walk-back、paper tune 复盘、瞄点校准或器材变更验证。
2. 记录器材状态：弓型、磅数、箭长、箭重、箭台/按钮/瞄具状态、弦距、nocking point、中心射出。
3. 记录距离、靶面尺寸、环境条件。
4. 每次只改变一个关键变量；如果必须改变多个变量，创建新的 session。

## 2. 实射

1. 每组箭开始前确认 session 信息正确。
2. 每支箭射完后，在靶面点击落点。
3. 按箭型标记：
   - `Fletched`: 羽箭
   - `Bare shaft`: 裸杆
   - `Test`: 测试箭或异常箭
4. 异常情况写入单箭备注，例如明显松手、撒放异常、风突变、靶纸破损。
5. 不在同一组内混入不同调弓状态。

## 3. 复盘

1. 先看组散布：均值、最大半径、平均半径。
2. 分别看羽箭和裸杆中心点偏差。
3. 判断偏差时优先比较“落点中心”，不要只看单支箭。
4. 对明显异常箭做备注，不急于删除；删除只用于误点或无效记录。

## 4. 调整

1. 根据 SOP 和模型建议选择一个调整项。
2. 记录调整前状态、调整动作和调整幅度。
3. 新建 session 复测。
4. 用两个 session 的落点中心、散布半径和稳定性对比判断调整是否有效。

## 5. 数据导出

1. 每次关键实验结束后导出 JSON。
2. 需要表格分析时导出 CSV。
3. JSON 用于完整回放；CSV 用于 Excel、Python 或后续统计模型。

## 6. 质量规则

- 没有备注的异常箭不能作为调弓依据。
- 一组少于 3 支箭只看记录，不做结论。
- 裸杆/羽箭对比建议至少 2 组以上。
- 调弓建议必须绑定具体 session 和具体器材状态。
